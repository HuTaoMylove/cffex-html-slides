# SVG 构图方法

在内容可通过形态、位置或局部变化讲清，或草稿连续出现介绍卡片时读取。本节提供可离线改用的构图方法与几何示例。先确定要展示的具体内容，再选择方法；它们不是整页模板，不要求按顺序使用，也不要求每页都有 SVG。品牌、字号、素材与交互规则沿用主 skill。

## 让图形承担解释

先把“介绍几项能力”还原为观众需要看见的东西：一个对象由哪些部分组成、同一个东西发生了什么变化、细节位于哪里、不同内容怎样归属。选择能把这个问题直接画出来的关系，而不是为每项文字找一个容器。

| 可视内容 | 构图方法 | 图形与文字怎样结合 |
| --- | --- | --- |
| 一个整体的组成、接口或部位 | 展开对象、剖切、分层或局部拆解；保留能认出整体的共同轮廓 | 部件名称与相关边缘对齐，用短引线落在具体部位；不要把每个部件再装进说明卡 |
| 同一对象的前后变化 | 用共用基准、轮廓叠合或配对位置显出改变；共同部分退后 | 直接标在改变处；需分别看清两种状态时才分开展示，保持对应位置可比较 |
| 整体中的关键细节 | 保留完整对象作定位，裁切或放大关注区域；主图与放大图之间有明确对应 | 简短批注贴住细节，长解释沿对象外缘排；不再另挂一列与图重复的要点 |
| 范围、包含、交集、归属 | 让对象进入实际有含义的区域，用轮廓、空白、括号或少量连线区分关系 | 名称沿所属区域定位；无需把每组都封闭成独立面板，面积不暗示未知比例 |
| 数值或数量变化 | 让位置、长度、面积或数量本身承载比较 | 共用尺度，直接标值；单位和口径放在可辨认的位置，不画装饰性假数据 |
| 可识别的场景与动作 | 选择与内容有关的视角和对象姿态，用轮廓、遮挡与局部细节建立情境 | 文字顺着可见对象组织；图形可以跨越文字分区，但不能遮挡正文或越过品牌安全区 |

确定主体后，去掉图形已经说明的重复句子，只留下名称、关键条件和仍需解释的部分。长文案仍用 HTML；使用 SVG 不意味着把段落全部写进 `<text>`。页面可以有一个整体画面，也可以有共享基准的多个对象，不必固定为“左图右文”。

## 从草稿开始改变骨架

- **用形状表示对象，用空白安放解释。** 先安排主体的轮廓与占用，再沿部位布置文字。图形不必被限制在矩形插图区，文字也不必形成等高矩形。只有真实边界、界面外框、图表区域等才需要相应容器。
- **把对应关系画进同一画面。** 差异落在共同基准上，细节来自可定位的局部，标签指向明确部件。连接线只补足无法靠位置表达的关系；不要用箭头串起原来互不相关的卡片。
- **允许有依据的简化。** 材料给出了对象与关系时，可以抽象成结构示意；没有截图不等于只能排文字。只简化已知内容，不补造部件、精确比例、实际界面或性能结果。
- **让构图承受删字。** 暂时忽略解释段，应该仍看得出主体及本页要比较、展开或放大的部分；补回文字后无需从头复述整幅图。若去掉 SVG 只少了装饰，就重新考虑图形的作用。

## 图文空间与几何落点

主体、标签和引线共同占用正文舞台，绘制前为三者留出空间。以下提炼自 [SVG Infographic 的几何方法](https://github.com/kyungseo/skillstead/blob/main/skills/svg-infographic/references/authoring.md)，并适配本母版：

- **文字容量。** 按实际字体与文案确定标签宽度，长解释用 HTML；拥挤时调整对象和标注的位置，不压缩字形。
- **共用锚点。** 标签与引线从同一部位定位；浏览器测量结果换回舞台坐标，避免混用屏幕像素与 viewBox 单位。
- **引线通道。** 利用对象旁的空白，避开文字与无关轮廓。箭头同时预留头部和线身，可用 `markerUnits="userSpaceOnUse"` 控制头部尺寸。
- **可见边界。** 描边、箭头与批注一并计入占用；检查曲线接续、遮挡与裁切，不能靠裁切隐藏溢出。

计算后仍在分组图中检查可见重量和文字归属。定位已清楚时，无需再补框、底色或解释画面的一句话。

## 可改用的局部代码

下面是三种几何机制的最小示例，主题分别为贴纸叠层、矩形面积和轮廓放大，均为教学示意。迁移时重新设计本页的对象、位置、比例与文案，不要把这三个主体换个标题反复使用。示例沿用 starter 的颜色变量；`viewBox` 对应 1400 × 600 正文舞台，在该尺寸显示时，标注为 24px。嵌入较小区域时需同步重新排布文字，不能任由缩放把标签缩到字号下限以下。

### 展开对象：共享轮廓，露出部件

这个例子把贴纸的三层沿相同方向展开，让轮廓与遮挡解释组合关系。层间距离只为阅读，不表示真实厚度。用于其他材料或系统时，先确认是否确有这种叠层关系；不能因为“有三条内容”就套三层图。

```html
<svg viewBox="0 0 1400 600" role="img" aria-labelledby="layers-title"
     style="width:100%;display:block;font:24px 'Times New Roman',KaiTi,serif">
  <title id="layers-title">贴纸的面材、胶层和底纸分解示意，不表示厚度比例</title>
  <g stroke-linejoin="round">
    <path d="M180 350 650 470 990 290 520 170Z"
          fill="var(--line-pale)" stroke="var(--blue-light)" stroke-width="2"/>
    <path d="M180 280 650 400 990 220 520 100Z"
          fill="var(--blue-pale)" fill-opacity=".65" stroke="var(--blue-light)" stroke-width="2"/>
    <path d="M180 210 650 330 990 150 520 30Z"
          fill="var(--blue-main)" stroke="var(--blue-deep)" stroke-width="3"/>
    <path d="M180 210 650 330 690 309 220 189Z" fill="var(--blue-deep)"/>
  </g>
  <g fill="none" stroke="var(--blue-main)" stroke-width="2">
    <path d="M930 162H1100"/>
    <path d="M922 256H1080V296H1100"/>
    <path d="M920 327H1050V432H1100"/>
  </g>
  <g fill="var(--ink-body)">
    <text x="1120" y="170">面材</text>
    <text x="1120" y="304">胶层</text>
    <text x="1120" y="440">底纸</text>
  </g>
</svg>
```

图形与标签各自保持对齐，但不必各占半页。需要增加解释时，沿部件位置加入 HTML 短句；不在图外重复一份三项清单。换成剖面或其他视角时，重新处理可见面、轮廓和引线落点。

### 配准变化：相同部分重合，新增部分显露

下面把宽度从 4 增到 6、高度保持 3 的矩形放在同一基准上。原面积与新增面积由几何直接表示，图中数值是确定的数学示例。迁移到实际数据时使用真实值；定性状态变化则使用轮廓与直接标注，不虚构数值。

```html
<svg viewBox="0 0 1400 600" role="img" aria-labelledby="area-title"
     style="width:100%;display:block;font:24px 'Times New Roman',KaiTi,serif">
  <title id="area-title">高为3，宽由4增加到6，面积由12增加到18</title>
  <path d="M170 120H570V420H170Z" fill="var(--blue-pale)"/>
  <path d="M570 120H770V420H570Z" fill="var(--blue-main)"/>
  <path d="M170 120H770V420H170Z" fill="none" stroke="var(--blue-deep)" stroke-width="3"/>
  <path d="M570 120V420" fill="none" stroke="var(--blue-deep)" stroke-width="2" stroke-dasharray="7 7"/>
  <g fill="none" stroke="var(--blue-main)" stroke-width="2">
    <path d="M170 90V76H570V90M570 76H770V90"/>
    <path d="M140 120H126V420H140"/>
    <path d="M170 452V466H770V452"/>
  </g>
  <g text-anchor="middle" fill="var(--ink-body)">
    <text x="370" y="60">4</text><text x="670" y="60">2</text>
    <text x="94" y="279">3</text><text x="470" y="506">6</text>
    <text x="370" y="281" font-size="36">12</text>
    <text x="670" y="281" font-size="36" fill="var(--paper)">6</text>
  </g>
  <g fill="var(--blue-deep)" font-size="32">
    <text x="955" y="242">3 × 4 = 12</text>
    <text x="955" y="318">3 × 6 = 18</text>
  </g>
</svg>
```

只有前后或部分与整体确需对应时才保留共同基准。若比较对象无法叠合，可并排配准相应部位；无需分别添加“标题、说明、总结”的外壳。需要动效时可以淡入新增区域，静态与打印仍保留全部内容。

### 放大细节：同一个源几何，两种观察尺度

局部放大应从原对象取出，避免独立重画后细节对不上。下面用 `use` 引用同一组轮廓，再用外层 `clipPath` 裁出放大窗口。示例轮廓不代表实际产品；应用时替换为本页有依据的对象几何，或对真实 PNG 作对应裁切。

```html
<svg viewBox="0 0 1400 600" role="img" aria-labelledby="zoom-title"
     style="width:100%;display:block;font:24px 'Times New Roman',KaiTi,serif">
  <title id="zoom-title">轮廓示意中的选中区域放大三倍，保留相同几何</title>
  <defs>
    <g id="zoom-object" fill="none" stroke="var(--blue-main)" stroke-width="3">
      <path d="M130 350C130 160 230 100 380 120S570 240 540 380L450 450H200Z"/>
      <path d="M180 350C180 200 260 165 370 180S500 250 480 360L425 395H220Z"/>
      <path d="M220 300C270 260 330 265 365 310S440 350 475 320" stroke="var(--blue-deep)"/>
    </g>
    <clipPath id="zoom-window"><circle cx="1100" cy="290" r="205"/></clipPath>
  </defs>
  <use href="#zoom-object"/>
  <g fill="none" stroke="var(--blue-light)" stroke-width="2">
    <circle cx="350" cy="290" r="68.333"/>
    <path d="M363 223 1063 88M363 357 1063 492"/>
  </g>
  <circle cx="1100" cy="290" r="205" fill="var(--paper)"/>
  <g clip-path="url(#zoom-window)">
    <g transform="translate(1100 290) scale(3) translate(-350 -290)">
      <use href="#zoom-object"/>
    </g>
  </g>
  <circle cx="1100" cy="290" r="205" fill="none" stroke="var(--blue-main)" stroke-width="2"/>
  <g fill="var(--ink-body)" text-anchor="middle">
    <text x="350" y="530">轮廓示意</text><text x="1100" y="550">局部 ×3</text>
  </g>
</svg>
```

圆形不是固定要求：窗口形状按细节与周边文字选择，也可无外框直接裁切展开。实际标签写明部位或必要倍率即可，无需再加“发现”“证据”或评价画面的一句话。跨页复制时替换所有示例 ID 及其引用，保持整份 HTML 唯一。

## 完成度与分组审阅

先检查对象比例、曲线连接、遮挡顺序、引线落点和标签位置，再看连续页面的主体轮廓是否服务于不同内容。描边、填充与留白共同建立重量，不把所有元素都画成相同的线框；也不靠渐变、阴影与底盘补救不完整的对象。

在主 skill 规定的分组图中确认：图形本身承载了对应、组成或细节，标签能就近读懂，长段落没有重新围成一圈卡片。SVG 数量增加不等于设计改善；同一幅图换标签反复出现时，回到本页具体内容重新构图。复用颜色、线条与标注方式即可，不要求复用主体。
