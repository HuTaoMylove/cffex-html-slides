# 内容构图与视觉节奏

在需要改善页面构图、整套节奏或实现自定义图解时使用。先读“从条目到演示画面”“识别陈列并重排”“从内容选择表达形式”“构图多样性与连贯性”；编写上屏文案时读“去掉版式附带的文案”，构图确定后读“排版精修”。成熟方案的相应小节、图标、素材复用、SVG 或动效章节按需读取。固定母版、颜色与字号规则见主 skill；以下是设计判断依据，不是主题到版式的映射表。

## 央企演示的视觉分量

以下是本项目用户已明确确认的风格，适用于央企、中金所场景下的图解与演示排版。

- **端正、稳健、有分量。** 用清楚的文字层级、规整的对齐、有力度的结构线和适度留白建立视觉秩序。保持专业的阅读密度，克制装饰。
- **中心节点以文字为主。** 优先采用白底上的深蓝文字，确需区分区域时使用浅底。用户已否定仅为强调中心而添加的黑色或深蓝实心圆块、徽章；不通过缩小这类色块继续沿用。深色实底仅在具体内容和品牌组件需要时使用。
- **主关系线要承担结构。** 1600 × 900 画布上的主连接线通常从 4–6px 试排，分组括线从 3–4px 试排，采用清晰可辨的内容蓝。主关系不使用 1–2px 的极细浅色线。表格细网格、辅助参考线按次要角色另行处理。
- **蓝色为主，金色克制点缀。** 金色是中金所品牌色之一，可按需强调少数关键字句、重要状态或局部结构，例如关键节点、括线及某段连接关系。控制金色的数量与面积，整体视觉保持蓝色主导；没有合适的强调点时可不用金色。同组等权的编号、步骤与节点保持同色，不为点缀任意挑出一项改成金色。浅金在白底、浅蓝底的小字与轮廓上辨识度不足时，直接使用蓝色。保留结构所需的线条分量，并在投屏尺度检查；金色的加入需要有明确的信息作用和足够的对比。
- **连线有明确落点。** 优先使用规整直线和折线，统一转角、端点、线宽与颜色，并留足文字间距。曲线仅在关系表达需要时采用，保持明确的走向与足够的视觉分量。
- **在实际展示尺度上判断。** 将中心节点、结构线、文字组一起检查，再看缩小后的分组图，确认线条仍然清楚、文字保持主体地位。视觉厚重落实到整体比例与结构，不靠增加深色面积或把所有元素一律加粗。
- **场景介绍主动用 SVG。** 从具体工作中的消息、录音、清单、台账和应用等对象入手，画出任务怎样处理、结果怎样形成。让 SVG 承担内容表达，并沿用上述线条分量与字体层级。


### 后续应用

- **先交代具体动因。** 用户要求案例讲清原来怎样做、哪里增加负担、为什么借助 AI 改造，以及相比原来改善什么。按源稿给出重复录入、层级定位、查找与换算等实际问题，并说明 AI 整理或对话搭建的作用。是否单独成页随讲述需要，不用泛泛的“提效”或无来源的成效数字代替。
- **先找到具体对象。** 从消息、清单、记录、待办、表单或已有成果入手，选取能贯穿讲解的一条内容。把输入、处理和结果的对应关系落实到画面，再精简为对象名称、原文片段、字段和必要标注。
- **让对象轮廓承载内容。** 消息气泡容纳交办原文，记录表呈现真实字段，技能文稿呈现生成规则。轮廓服务于识别，内部文字和连线共同解释业务；无需另挂一圈功能介绍或页底总结。
- **连贯与变化同时保留。** 同一案例延续需求名称、字段和状态，页面分别聚焦登记、跟进或搭建。重心随讲述推进，复用字体、线条和标注方式；四格场景、左右转换和三页案例顺序均按内容选用。
- **准确性进入图形。** 区分 AI 整理与流程读取、自动写入与预览确认；“如有附件”“当前停用”等条件贴近对应对象。依据材料绘制的界面和对话标为示意，较长的解释留在讲稿中。

构图后沿用上方的央企视觉分量与蓝金主次，再按“排版精修”完成检查。分组图中应能辨认核心对象、处理方向和结果；放大后文字能就近归属，连接落点明确，字段与规则可读。用户已认可的页面用于校准这些具体表现，后续局部修改延续已确认的构图和风格。

## 从条目到演示画面

原文分了几条，不等于画面就分成几块。先判断哪些信息共同支持一个结论，哪些是观众需要看见的对象，哪些属于次要细节，再安排它们的空间关系。为每条内容套上相同的标题、说明和容器，容易把演示做成资料清单；移除容器也不会自动产生主次。

分别判断整体结构、局部表达与视觉样式。整体结构决定对象如何对应、展开、包含或比较；局部表达决定用轮廓、标签、数据标记还是图片细节来承载内容；视觉样式再统一字体、颜色、线条与间距。出现卡片堆叠时先改整体结构，只把局部模块换成圆形、图标或 SVG 路径，通常仍保留原来的阅读方式。结构相同但曲线、对齐或标签粗糙时，则精修局部，不必重排整页。

视觉重心由相对关系形成，不只靠字号。一个对象可以通过更完整的轮廓、更集中的对比或更大的画面占用成为主体，解释文字沿相关部位排布；关键文字也可通过聚合、断行、字重和周围留白成为主体，依据退到清楚的次级位置。纯文字页同样需要有意的组合，避免整页都是等量段落。

以下是可迁移的构图思路，按材料需要使用，不是必选版式：

- 展示成果时，以成果本身或有依据的结构示意为主体，裁切聚焦关键区域，批注贴近对应位置。补充信息围绕对象展开，而非把图片塞进一张卡片，再将解释平铺在旁边。没有真实画面时，不伪造截图或数据。
- 讲解差异时，把对应内容沿同一比较轴对齐，让关键差异成为视觉重点，共同部分弱化。只有少量关键差异时无需扩展成完整大表；确需逐项查阅时保留表格。
- 解释判断或机制时，让关键文字、对象和证据组成一个整体。可借助括号、局部轮廓、衬底或空间包含关系建立归属；动作顺序明确时再用方向连接。支持性细节不必各自占据同样大小的区域。

局部对齐让相关信息成组，跨区对齐帮助对应比较，留白区分层级，适当层叠或局部放大引导视线进入重点。空间表达须有内容依据：视觉面积用于强调时不冒充数量比例，前后层叠不凭空创造业务层级。图形、文字和空白共同构成页面，边框只在需要明确边界时出现。

## 识别陈列并重排

卡片陈列按阅读体验判断，不按 CSS 类名或有没有圆角判断。几个区域各有标题与解释，彼此只靠位置并排，即使去掉底色、改成不等宽、加编号或箭头，仍可能是陈列。先辨别页面需要平行查阅，还是要讲清一个判断、变化或机制；前者可以均衡排布，后者需要让内容共同组成画面。

用位置互换帮助诊断：调换几块内容，除顺序外几乎没有损失，说明它们没有建立空间关系。此时找到材料中的具体对象、共同问题或关键差异，再把解释放到对应部位。流程虽有顺序，如果盒子里仍只有“步骤名＋功能介绍”，也容易像产品清单；展示同一条消息、记录或任务在步骤中的变化，能让观众看见流程究竟做了什么。无需每一步都画成独立界面。

重排时先画出主体的大致轮廓，以及解释落在哪个部位，再决定哪些文字还需要独立成段。草图中若仍是几个装文字的矩形，就还没有完成这一步。可以先用 SVG 把对象、共同基准或局部差异建立起来，再让 HTML 文字融入其中；具体做法与可改用的局部代码见 [SVG 构图方法](svg-composition.md)。不必把每页都改成图解：实际需要查阅的表格保留，承担讲解的页面则应让人看见讲解对象。

以下示例说明重排依据，不要求固定采用这些画法：

- **功能速览。** 三种工具各自写介绍、场景和例子，仍是三份简介。若本页判断是“长信息能变成可执行要点”，可让长文、群聊、会议片段共同指向一份摘要与待办，功能名称贴近对应来源；若目的确实是逐项查阅产品，采用清楚的清单即可。
- **自动化机制。** “触发／处理／生成／落表”四个等大的盒子只给出步骤。围绕一条具体需求展示原文、被清理的内容、保留或润色后的正文和最终记录，旁注解释触发条件及处理边界；用连接表示实际流转，用状态变化承载讲解。
- **成果介绍。** 左边放一句需求，右边再列三项能力，仍可能是两组文案。若要讲“需求变成应用”，让应用的关键结构成为主体，需求中的约束与相应结构对应，再说明发布后的使用入口。缺少真实截图时可用有依据且标明的结构示意，不伪造实测成果。

缩略总览先比较各页的主体轮廓与阅读路径，再在分组图中核对对象、证据和解释的对应关系。出现连续的等量分区时，依据各页的表达任务决定保留还是重排；不能用更换卡片形状、插图、配色或转场证明构图已经改变。技术检查与这项视觉判断分别完成、分别报告。

也检查判断是否被另挂成一条页底文案。主体已经展示了动作、差异或结果，再用横线隔开“本页关键／所以／共同作用＋金色总结”，容易让观众读完画面后又进入一个独立区域。重复的讲解句移入讲稿；仍需显示的判断贴近它所解释的对象，或用于组织标题、比较轴与结果状态。例如工作流中的“保留上下文”，应由正文流转与元信息保留路径共同表达；不再在图外补一句口号。去掉横线后仍孤立的总结句同样需要处理。真正以总结为任务的页面，可以围绕判断本身构图。

## 去掉版式附带的文案

先确定观众需要看到的事实、对象名称与必要解释，再安排位置。内部构思中的“判断、证据、发现、边界、启示”帮助设计者组织材料，不意味着页面需要一组同名标签。文字本身也是设计材料；给每段补一个小标题、给每页补一个总结，容易让页面成为带讲评的模板。

检查一句话是否提供了实际信息或必要定位。只是重复标题、宣告“这很重要”、解释“这里展示了什么”、为下一部分转场，通常留在讲稿即可。删除后同时去掉其专属容器，再重排主体；不要为了保住某个色块或填满留白另编一句替代话。

以下是语义改写示例，不是字词黑名单，也不是要求每页采用的栏目：

| 常见包装 | 处理方式 |
| --- | --- |
| “接住需求”“承接价值” | 材料确有登记、分派或跟进动作时，直接写具体动作与对象；无实际动作就删除 |
| “证据：……” | 直接呈现相关数据、样本或原文片段，保留必要出处、单位和口径；不另造“证据”徽章 |
| “发现：……” | 有材料支持的发现直接写成具体陈述，可作为标题；不再用摘要、标签和页底句重复一遍 |
| “注意：仅统计已完成项目” | 确属必要范围时写入图表副标签或列头，例如“已完成项目”；不能把删提示框变成删口径 |
| 图表下再补“数据说明了变化”“让信息真正产生价值” | 若图表与标题已表达全部含义，删除这句及其横线、底色或图标 |

保留有用的定位词，如真实对象名称、处理前后、时间、单位与实际状态。标题、对象标签和必要说明各自承担职责，不能为了减少文字而让图形难以辨认。判断关键在于信息是否必要、表达是否具体；真实内容中的“发现问题”不因包含“发现”而被机械删除。

## 从内容选择表达形式

选择时对照本页的关键判断、证据与具体对象，以下表达可组合使用。

| 表达任务 | 可选表达 | 判断依据 |
| --- | --- | --- |
| 强调判断或提出问题 | 短句与支撑信息、问题与回答、文字对照 | 用文字层级、位置和留白突出重点；无需为短句补一幅象征性插画，字号仍遵守主 skill |
| 展示对象或成果 | 真实画面与批注、样本组合、局部放大、必要的结构示意 | 对象本身承载证据，以裁切和标注突出相关部位；示意图不替代实际成果证据 |
| 解释细节 | 清楚分层的文字、批注、圈选、局部图解 | 指向明确部位或论据，以位置与形态帮助定位和理解，避免重复整段正文 |
| 比较或呈现数据 | 对照表、配对构图、矩阵、按数据关系选择的图表 | 共享比较维度；比例、位置、长度与数量编码有真实依据，不能用示意面积制造定量印象 |
| 表达关系或过程 | 树、分组边界、网络、流程、时间线 | 先确定连接、方向和分组的含义；只有真实顺序、流转或因果才用流程箭头 |
| 建立情境或具象化概念 | 简短场景描述、真实图片、场景插画或视觉比喻 | 对象、动作与视角帮助观众进入具体情境；仅因主题相关而添加的物件不足以成为主体，比喻不冒充实际结构 |

评估视觉元素时，同时看它是否帮助理解内容、聚焦重点或建立情境，不只看它是否增加了文字之外的新信息。尝试去掉它：若这些作用没有损失且页面更集中，就删除或弱化；若失去关键对象、注意力引导或场景识别，则保留并与文字共同构图。SVG 适合需要精确控制几何、局部编辑或分组动画的图解。

## 构图多样性与连贯性

比较连续页面的视觉重心和信息关系，而非配图是否不同。每页都采用“标题、几段说明、一幅独立插画”，或反复平铺几组“模块标题＋解释”，即使插画、列数和位置不同，也容易产生相同的阅读体验。

观察正文的整体轮廓：焦点在哪里，依据与焦点如何对应，哪些位置留给解释与停顿。若不同表达任务的页面都只剩若干相近的矩形分区，重新组织其中页面的主体与支撑关系。仅改成不等宽、斜向错落或换一种分隔线，不能替代这一判断；有意的连续比较可以沿用相同骨架。

按叙事形成密度与停顿：证据较多的页面充分展开，转折和收束聚焦少量关键信息。并列查阅可保持均衡，聚焦页可围绕一个对象展开，前后解释同一对象时可延续它的识别特征。多样性来自讲解需要，不规定布局轮换、主视觉比例或每页图形数量。

## 用内容页试排构图

构图方向不确定，或用户持续反馈单调时，从实际材料中选取能暴露问题的内容页做小范围试排。选讲解对象复杂或图文需要配合的页面；封面的大面积装饰无法证明正文也能成立。简单文案修订、已有清楚构图的页面无需增加此步骤。

保持要传达的事实与必要条件一致，尝试阅读方式确有区别的草图。例如同一组变化，可沿共同基准对照，也可在同一个对象上显出改动；重画视角、对象占用和标注位置，不能只交换左右栏、改颜色或圆角。试排用本页实际文字与字体，先看主体轮廓、空间关系和文字容量，再完成细节，不靠占位短句掩盖真实内容放不下的问题。

将候选放进一张分组图比较：哪版让人更快找到关键对象或差异，解释是否就近读懂，必要内容是否完整，与相邻页是否形成合适节奏。按这些具体表现自主选择；草图已有明显优劣就结束比较。用户要求看方案时再交付候选，平常无需额外确认，也不为每页生成固定数量的版本。

选中后延续其线条、文字角色与标注方式，其他页面仍随内容重新构图。不要把试排成功的主图变成整套反复替换文案的模板；候选文件放临时目录，正式交付只保留选定页面与必要资产。

## 排版精修

在主体与信息关系已经成立后，用本节完善页面。精修的目标是让观众自然看见重点、沿清楚的关系阅读，并感觉各处处理出自同一套设计。先修影响整页的占用、对齐和疏密，再处理文字与图形细节；若问题仍是内容没有主次，回到构图，不在错误骨架上反复微调。本节可离线执行。

精修前先按“去掉版式附带的文案”清理多余层级。把重复提示和卡片边距修得更一致，仍不能解决内容包装过重的问题。必要对象与信息保留下来后，再调整比例、线条、断行和光学对齐。

### 对齐轴与留白

- **让位置互相有依据。** 在正文范围内，根据主体边缘、比较轴或文字起点建立少量主对齐轴，让关联的标题、正文、标签与图形边缘复用这些轴。需要比较的内容对齐相应项目或基线；叙述段落通常左对齐，短标签可按所指对象居中。非对称构图也要看得出承接关系，避免每块内容独立居中、靠多个无关偏移量“摆顺眼”。品牌页眉与正文载体沿用各自既定位置。
- **让空白区分归属。** 标签与所指对象、模块标题与所属正文保持紧密；独立信息组之间留出更明显的间隔。跨页复用同类间距，再按内容做局部调整。避免用 `space-between` 撑满高度，使原本相连的内容被推向两端；需要按共同刻度或比较轴分布时仍可均匀排列。
- **平衡可见重量。** 看文字密度、深色面积与图形实体，不只看容器是否等宽等高。正文较密的一侧可通过列宽、行长或周围空白与另一侧平衡；PNG 的透明留边和 SVG 的空 viewBox 边缘不应冒充主体边界。必要时微调可见对象位置，保持图表尺度与品牌资产比例准确。内容少时主动聚焦，内容多时充分展开，留白不按固定占比填满。

### 文字轮廓与层级

- **稳定文字角色。** 在主 skill 的字号范围内，为正文、模块标题、辅助信息选择少量稳定规格；同角色跨页复用，局部变化需对应信息层级。不要因每页字数不同而连续试出一批近似字号。强调集中在决定本页判断的词句，用已有的字重、颜色或位置形成足够的区别，避免每段都加粗或每项都用金色。
- **按语义整理断行。** 先在真实字体下确定文字区域宽度，再查看整段的行形：避免关键短语被拆散、长短行偶然交替，以及孤字尾行。正文区的小标题或关键短句可在语义边界有意断行；正文段落优先自然换行，固定品牌页眉沿用母版。用改写和调整局部列宽解决问题，必要时保护数字与单位等短组合，不能给整段套 `nowrap`、压缩字距或手工塞空格来挤入版面。跨栏对照按对应项对齐，不为凑成等高强制相同行数。
- **分清行距与段距。** 楷体多行正文可从约 `1.4–1.6` 的行高试排，再按实际字形和行长校准；这是起点，不覆盖母版标题样式。段间距要能区分论点，又不能让同一组的解释散开。短标签、数据行与长段落按各自阅读方式处理，不把一套行高套遍所有对象。单位、标点和中英混排在最终显示尺度下检查，保持自然字距与基线。

### 图文与细节收口

- **让解释贴住所指部位。** 图片裁切保留论据所需的上下文，批注靠近对应位置；引线的末端清楚落在对象上，并与文字留出可辨的间隙。对象、批注和图例共同占据页面，不把主图缩小后腾出一大片空地容纳零散说明。裁切、放大或示意均不能改变证据含义。
- **统一同角色的细节。** 正文构图中的同类边界、引线、节点、圆角和内边距沿用一组样式；线条按作用区分主次，辅助线退后仍可辨认。检查边缘、转角、端点和相邻元素是否出现“几乎相接”的尴尬缝隙：需要连接就接准，需要分离就留清楚。阴影、底色和边框各有作用才保留，不用叠加装饰补救对齐或比例问题。
- **让表格与数据标签也有排版。** 列宽随内容分配，文字说明通常左对齐，同单位数字沿可比较的边缘或小数位对齐；共用单位可放入列头，前提是不丢失口径。行间留白支持扫描，重点行或关键差异获得局部强调，辅助网格不与数据争夺注意。没有比较任务时，不为了整齐把文字强制变成表格。

### 用分组图完成精修

沿用每张 4 页、密集页每张 2 页的审阅方式。先看页面缩小后最先吸引视线的是否是核心内容，连看各页时重心与密度是否有意变化；再看文字分组、对齐边缘与图文结合。细节在拼图中无法辨认时，只把相关文字块、标签或连接处按画布原尺寸合为一张局部对照图，保留足以判断归属的周围内容。

按看到的症状修正，而非统一套一种美化效果：

| 观察到的症状 | 优先调整 |
| --- | --- |
| 内容齐全，却像零散部件拼起来 | 主对齐轴、组内归属、主体与解释的距离 |
| 容器已对齐，视觉上仍歪或一侧偏重 | 可见轮廓、素材空边、文字密度与对象占用 |
| 每块都整齐，整页仍平而散 | 核心与支撑信息的相对重量，以及组内外留白 |
| 放大后文字显得毛躁 | 实际字体、语义断行、行距、孤字、单位与标点 |
| 单页好看，连看却不像一套 | 同角色的字号、间距、线条和批注处理；保留内容驱动的构图变化 |

修正后复看受影响的分组，确认没有把拥挤、偏重或断行问题转移到邻近区域。已有清楚的焦点、自然的阅读路径、稳定的细节语言，且没有可指出的明显排版问题时即可收口；不设装饰数量、版式配额、精修轮数或主观打分门槛。

### 演示构图：用局部对比组织重点

[Figma 演示设计](https://www.figma.com/resource-library/presentation-ideas/)强调有目的的文字与色彩重音、定制视觉、清楚的叙事和留白。适配时先找到关键判断或证据，让局部对比集中在那里：相关短句聚合，解释与对象部位对齐，留白隔开次要信息。截图可裁切到讲解区域，再用邻近批注承接；文字也可以独立形成主体，无需配满图形。

品牌字体与字号保持不变，通过字重、断行、位置、对象占用和疏密建立重点。连续页面的变化来自问题、证据和结论的不同阅读需要；不照搬外部方案的大字、鲜艳配色或边框，也不机械轮换左右栏。

### 场景插画：先让对象与动作成立

[unDraw](https://undraw.co/)提供贴合情境、可适配品牌色的简洁矢量插画，并以多层对象组织画面。借鉴时先确定观众需要识别的对象、动作或使用情境，再决定画哪些部分。主体保留清楚的轮廓与识别细节，次要对象以浅色、简化细节或退后的位置降低重量；轮廓、填充和遮挡共同建立层次，不给所有部件同样的描边与强调。

颜色替换只解决风格协调，还需检查画中动作、视角与本页内容是否一致。素材不可用时，可用本地几何与内联 SVG 画必要的对象示意，或用已有图片、文字表达；不因为材料提到“协作”就固定补人物、电脑或抽象装饰。自绘示意不冒充真实产品画面。

### 图标系统：统一形态，按显示尺度校准

[Lucide 设计语言](https://lucide.dev/contribute/icons/design-principles)可迁移的是一致的造型、低细节密度、顺滑曲线、清楚间隙与光学平衡。图标用于识别，同组保持视觉重量协调；大幅主体需按其角色重新设计。具体路径来源、离线自绘基线和审阅方法见下节“图标选用与造型”，不依赖在线图标库。

### 数据图表：让问题决定编码

[Datawrapper 图表选择](https://www.datawrapper.de/blog/chart-types-guide)以要说明的关系筛选图表。先确定观众要比较什么，再核对数据是否支持这种编码；以下是可选起点，不是固定映射或图表配额。

| 要回答的问题 | 可选起点与取舍 |
| --- | --- |
| 谁更多、谁更少？ | 条形图便于比较数量；标签较长时可横向排条，按讲解需要排序 |
| 随时间怎样变化？ | 折线图呈现趋势；只有少量离散时点时可用柱形图，只关注前后差异时可用斜率图 |
| 整体由什么组成？ | 堆叠条形或百分比条形；少量部分强调整体时可用饼图或环图，精细比较差异时优先长度编码 |
| 同一类别内有哪些差异？ | 分组条形或点图；多组趋势拥挤时可拆成共享刻度的小图，保持可比性 |
| 两个变量是否有关联？ | 散点图；位置表示两个变量，第三变量确有数据时再考虑大小编码 |
| 数量从哪里流向哪里？ | 有来源、去向及流量数据时可用桑基图；只有操作顺序时使用定性关系图，不编造流量 |

关键系列保持突出，参考系列与网格退后，标签靠近所指数据。核对单位、时间范围、比较口径及比例分母；没有定量依据时回到文字、表格或明确的定性图解，不画虚构比例和趋势来增加设计感。

### 对象动效：安排注意力与状态变化

[Keynote 对象动画](https://support.apple.com/en-ae/guide/keynote/tanf96d92cb6/mac)支持对象移动、缩放、透明度变化及动作的顺序或同时组合。借鉴时区分“新信息出现”和“已有对象变化”：前者按语义分组进入，后者保留对象的识别特征，让观众容易跟随变化。先确定起始状态、结束状态及要强调的部位，再判断动作是否有助于讲解；并列比较通常需要同时可见。

在本 starter 中优先用已有转场与 reveal 表达这些需要，具体实现见“动效搭配”，无需复现 Keynote 的全部效果。关系线与解释保持配对，静止时完整可读；不让依次弹出的装饰成为页面唯一的阅读顺序。

## 图标选用与造型

图标承担快速识别与定位，先判断它在当前内容中是否有用。同一个符号应保持同一含义；抽象概念没有清楚符号时，用文字即可。图标的造型一致性与页面构图多样性分别判断，不为避免重复而让同组图标采用不同画法。

- **复用成熟形态。** 常见对象或动作优先选取本地资产、已安装包或用户素材中语义贴合的成熟图标，例如 Lucide；同组沿用同一图标家族。使用准确的源路径，保留原有比例、曲线和关键识别特征，再适配品牌色与显示尺寸，不凭记忆拼出一个“像库图标”的近似形。无需固定使用某个库或安装整套依赖；没有合适素材时，按下述本地基线自行设计，或省略图标。离线环境无需等待下载，也不把自绘图标标成某个库的原版素材。
- **按角色决定尺度。** 辅助图标与其标签、正文形成主次，不因页面留白而放大。小尺寸图标适合简洁识别；作为大幅主体时，重新判断对象的轮廓、细节和画面关系，可采用适合该尺度的对象图解或插画。直接放大工具栏式符号，或加大底盘，不自动成为主视觉。
- **保持轮廓完整与曲线自然。** 自绘时保留对象最有辨识度的结构，检查轮廓闭合是否符合对象、连接是否自然、曲线是否顺滑，以及内部间隙能否清楚分辨。同组统一端点、转角、细节密度与线条风格；不要仅用几根直线和圆弧凑出大概意思，也不靠添加纹理或装饰补救基本造型。
- **以实际显示效果校准。** 同尺寸的不同图标不一定同样显眼，需按可见轮廓、疏密和视觉中心微调，使同组重量协调。检查最终画布中的描边粗细；小 viewBox 放大后，原始 stroke-width 会随之放大，不能直接套用画布像素值。优先等比缩放，避免横纵拉伸；线框、实心与双色处理可选，按本组语义与整体风格保持连贯。
- **让衬底有明确作用。** 圆底、外圈和徽章可用于状态、分组或局部对比；若只是给每个图标套壳，先尝试移除。检查是否抢过对象或文字、形成多余的重复轮廓，或让图形显得空大。不要将“图标＋圆底＋标签”固化为各页的默认模块。

### 离线自绘基线

以下提炼自成熟线性图标系统，可作为没有源素材时的起点；不是所有图解、插画和主视觉的统一规格。

- **网格与留边。** 简洁线性图标可从 `viewBox="0 0 24 24"`、2 单位描边开始，描边外缘与画布至少保留 1 单位距离。以此统一同组的坐标与细节尺度，再按最终尺寸调整实际线宽；不要把这套局部单位当成 1600 × 900 画布像素。
- **端点、转角与曲线。** 该画法可用 `fill="none"`、`stroke="currentColor"`、`stroke-linecap="round"`、`stroke-linejoin="round"`；圆角接头不等于轮廓已有圆角，需要时仍用圆角矩形或曲线路径。优先用简单圆弧、二次曲线；拼接曲线的切线方向保持连续，减少多余控制点，避免弯曲处出现鼓包或折痕。
- **间隙与细节。** 以上网格中，独立部件及内部空隙可从至少 2 单位的可见间隙起步，以描边外缘而非中心线判断。保留识别所需的结构，删去缩小后粘连或只增加噪声的细节；边缘、内孔与部件连接在最终尺寸下仍要清楚。
- **光学平衡与重量。** 对称形状先几何居中；不对称形状再按可见重量微调，不能只对齐 SVG 的外框。将同组图标并排、暂时移除底盘，缩小或轻微虚化后比较：某个图标明显更黑、更空或偏向一侧时，调整可见占用、部件疏密与位置，保留同组连贯的描边风格。

这些原则已在本节给出，离线直接使用即可；[Lucide 设计语言](https://lucide.dev/contribute/icons/design-principles)仅作来源与可选延伸阅读。采用外部图标时，将所需路径写入内联 SVG，并随成品保留相应许可声明；成品不依赖 CDN、在线图标请求或图标字体，也不改变 PNG 资产规则。

沿用分组拼图审阅，先看图标是否易识别、是否与邻近文字协调、同组是否重量一致。发现轮廓疑似变形、连接生硬、间隙粘连或缩略图无法判断时，将相关图标按实际显示尺寸合到一张局部对照图再看，无需逐页截图。质量不佳时优先替换准确路径、修正几何或简化；增加外圈、阴影与动效不能替代造型修正。

## 主体素材的复用边界

审阅时按观众看到的图形判断重复，不按文件名、SVG ID 或代码是否重新生成判断。同一主体改色、镜像、换文字、调整大小与位置，通常仍会被识别为同一素材；即使页面布局不同，也可能造成视觉疲劳。

发现无内容依据的素材重复时，先判断是否需要这幅图。可以删除图形，改用更直接的文字或证据，或调整整体构图。确需新的图解时，才根据具体对象重新设计形态、视角、内部构成与识别细节；局部特写或剖面要揭示新的信息，单纯裁切和添加装饰不能解决重复。

连续解释同一对象的不同部位或比较前后状态时，保留识别特征有助于观众跟随。固定品牌资产和辅助图标不按主体素材重复处理。

## SVG 与 HTML 协作

### 用 SVG 组织具体内容

先说明图形要让观众看见什么，再决定路径与形状。SVG 可直接构成正文主体，也可只承担某处精确表达；无需每页配图。构图阶段就按 [SVG 构图方法](svg-composition.md)中的内容选择表与局部代码，考虑对象展开、共用基准、局部放大、空间分组与图文嵌合；图文位置再按其中“图文空间与几何落点”校准，避免在已经排好的文字模块旁边补图。

这些是表达能力，不是需要轮换的版式。若 SVG 只是把若干卡片改画为 `<rect>`，或给每条文字配一个圆底图标，内容组织并没有改善。图形应吸收一部分解释任务：边界表达范围，配准显出差异，局部放大展示细节；对应的长段落可缩成贴近对象的直接标注，不再把同样意思在图旁写一遍。

可以基于材料绘制经过简化的示意，不要求每幅图都有真实截图或可下载素材。保留已知的对象、部件和关系，只简化无关细节；外形仅作概念表达时采用清楚的示意画法，不冒充实际界面、设备结构或测试结果。把轮廓、曲线、比例与局部识别细节做完整，图标放大不自动成为对象插画。纯文字、图片与图表已经能清楚表达时，保留它们即可。

### 几何与文字共用坐标

将 SVG 用于对象轮廓、插画细节、图表几何、分组边界和连接线，用 HTML 排版标题与长标签。让两层共享一个有明确宽高的相对定位容器；SVG 用同宽高的 viewBox。按对象或图形坐标对齐 HTML 标签，避免标签悬空或引线穿字。不要分别缩放图形和标签。

- 线宽通常 2–4 个画布像素，主关系深蓝或主蓝，辅助边界淡灰蓝；金色保留给核心文字或局部节点。
- 内联 SVG 的 `defs` ID 使用页级前缀，避免跨页 marker 引用错位。图形与文字均不放在字号规则之外。
- 用 SVG `<text>` 时明确对应字体栈并验证实际命中；不要先做很小的 viewBox 再放大，让标签实际字号失控。多行标签优先 HTML。
- 纯几何且旁边已有完整解释时使用 `aria-hidden="true"`。图解独立承载信息时用 `role="img"`、唯一的 `<title>` / `<desc>` ID 和 `aria-labelledby`，或提供相邻等价文字。
- 可用分组、裁切、蒙版和层叠突出局部、组织景深或融合图文，按实际需要选择；不让滤镜或渐变模糊信息边界。引用截图时仍用 PNG，示意界面自然标明“结构示意”。

## 动效搭配

转场选择可以结合阅读关系：fade 保持比较稳定，push 表达推进，lift 表达递进，focus 聚焦重点，wipe 配合横向展开。这些是选择依据，不是页面类型到效果的固定映射。

选用页内动效时，先确定讲解中的注意力转移，再选择分组和动作。先让静态构图成立，按主体、证据和局部解释安排入场；逐块弹出卡片不能补足缺失的视觉主次。以下是可组合的表达方式：

- 对象或场景用 `data-reveal="fade"` 整体出现，关键部位的批注随后进入；图形与它的长标签放在同一视觉分组中，保持对齐。
- 需要突出的局部轮廓、圈选、括号或实线引线可用 `data-reveal="draw" pathLength="1"` 描绘，邻近解释用淡入承接。描线也可用于非流程图形，不必为使用动画增加连接关系。
- 与主体对应的说明或判断可用 `data-reveal` 抬升进入，将视觉焦点带到相关部位。并列比较可整体淡入，保持同时可读，不将并列关系演成执行步骤。

starter 根据 reveal 元素的 DOM 顺序安排短时错峰，HTML 的阅读顺序应与讲解顺序协调。SVG 只支持实线 path/line/polyline 描线；对于闭合轮廓，可将实线轮廓与静态填充分开，避免实线属性改变后出现填充闪动。已有 SVG 定位变换应放在内层，动画加在外层视觉分组，避免入场 transform 覆盖几何定位；描线元素不要再嵌套于 reveal 分组。
